# v0.5.5

## Changes

- Tap ring collapses faster: 260 ms → 180 ms, and it now shrinks quickly at the start instead of lingering, so it is gone by the time the cursor moves on.
- Settings: removed the "Test checklist" entry from About.
- Settings: removed the "Button icon size" slider. It had almost no effect, because the icon was already capped at 56% of the button diameter. Icons now always use that 56% and scale with the button size.

## Install

`versionCode 18`, same signing key as before. Installs over the previous version.
