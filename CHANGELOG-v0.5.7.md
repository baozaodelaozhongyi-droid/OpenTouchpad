# v0.5.7

## Material Design 3 Visual Style

**Buttons and touchpad redesigned in Material 3 style:**

- **Buttons**: Solid flat color with thin stroke instead of gradient + outer glow. All buttons now use the same style — move/resize keys no longer have a special accent color (they're distinguished only by their icons).
- **Touchpad**: Solid color with thin stroke (already close to M3 in v0.5.6).
- **Drag-lock indicator**: The drag-lock button still turns terracotta when active, but with the flat M3 treatment.
- **Floating ball**: Keeps its existing glow + gradient style for visibility against any background.

**Colors:**
- Dark mode: surface-variant (`#3A3936`) for buttons, darker for touchpad
- Light mode: warm off-white (`#F5F4ED`) for buttons, slightly darker for touchpad
- Strokes are more visible (`0x33` alpha dark, `0x40` alpha light)

The panel now has a cleaner, more modern look consistent with Material 3 design language.

## Install

`versionCode 20`, same signing key as before. Installs over the previous version.
