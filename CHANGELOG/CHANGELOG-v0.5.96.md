# OpenTouchpad v0.5.96

### 交互响应可靠性与手势派发稳定性专项修复 🛠️

针对偶发**双击悬浮球无响应**、**点击触控板按钮无响应**以及**桌面点击应用打不开**等交互失灵问题进行了全链路根因修复：

- **消除手势注入死锁与穿透态残留（修复触控板点击与桌面点应用打不开）**：
  - 修复穿透点击处于 50ms 等待期时若触发窗口重建（如 `ACTION_UP` 同步重建、键盘自动收起、配置变更或展开/收起），取消挂起任务但未重置 `isDispatching` 导致后续所有注入手势永久卡死在队列中的死锁；
  - 为穿透与直发两条手势路径统一引入单调代数（`gestureDispatchGen`）与超时看门狗，系统息屏或异常丢弃 `GestureResultCallback` 时自动解锁队列并恢复面板可触摸；
  - 改为派发瞬间基于当前窗口动态判定是否穿透（合并 `getLocationOnScreen` 与 `LayoutParams` 坐标并留出 2px 余量），避免切到悬浮球后误设 `FLAG_NOT_TOUCHABLE`；新增 `passThroughSynced` 同步校验、`endDrag` 续接手势插队到队首以及非续接队列上限保护；
  - 穿透切入时主动取消活跃按钮/触控板/悬浮球长按计时，各触摸监听器在穿透期间安全放行 `ACTION_UP` / `ACTION_CANCEL` 清理状态，杜绝残留按压态与延迟误弹动作选择器。
- **大幅提升悬浮球双击识别率**：
  - 将悬浮球双击等待窗口由 `190ms` 放宽至 `260ms`（并附带 `100ms` 主线程抖动宽限），且在第二次 **`ACTION_DOWN`** 瞬间即锁定双击资格并取消单击计时，不再因抬手稍慢超时失效；
  - 提升点击容差至 `maxOf(scaledTouchSlop, 10dp)`（上限为滑动阈值的 80%），第二次抬手只要未达到滑动阈值且未滑回取消即触发双击，彻底消除 `6dp–25dp` 微滑被静默吞掉的死区；等待双击期间暂缓面板重建。
- **修复触控板按钮边缘点击偶发丢失**：
  - 按钮点击判定改为基于**未形变屏幕矩形 + 触摸容差**（且原地微动 `<= slop` 始终有效），完全免疫按压反馈 3D 倾斜、0.92× 缩放与 3dp 下沉及面板展开缩放动画造成的局部坐标偏移；按钮脱离窗口时自动清理长按回调。
- **窗口过渡与状态一致性加固**：
  - 修复系统关闭动画缩放或息屏中断过渡动画时，新窗口可能停留在 `alpha = 0f` 且保持可触摸而静默拦截桌面点击的问题；
  - 常规面板移除改回安全异步 `wm.removeView`，屏幕尺寸/配置变更与键盘自动收起统一延后到活跃触摸与手势派发结束后再异步重建，避免触摸途中撕毁 `InputChannel`；`toggleMinimize()` 依据当前实际可见窗口切换状态，并加固触控板边缘防误触坐标与非有限坐标防护。

## Install

`versionCode 109`, `versionName 0.5.96`, same signing key as before. Installs over previous versions.
