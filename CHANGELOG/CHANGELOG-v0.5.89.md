# OpenTouchpad v0.5.89

### 拖动触控板移动时的整板方向形变动效 ✨

为拖动「移动触控板」把手时的面板位移加入了跟随移动方向的整板弹性形变与回弹效果：

- **全方向果冻拉伸与 3D 透视倾斜**：
  - 拖动触控板移动时，触控板本体与四周所有按键作为一个整体沿移动方向柔韧拉伸、垂直方向保面积微压扁，同时叠加方向性 3D 透视倾斜（前缘抬升展宽、尾缘收束）与细微惯性中心滞后，左右上下及斜向移动均可直观感知方向感；
  - 根据移动把手所在槽位计算抓握力矩，横向/纵向拖拽时产生轻盈自然的惯性微摆（兼容 4 / 8 / 12 / 16 / 18 键及自定义布局）。
- **弹簧动力学跟手与 Q 弹回弹**：
  - 由 `Choreographer` 按屏幕刷新率驱动子步弹簧积分，拖动时丝滑跟手，中途停顿、贴边触壁或松手时自然弹性回弹并平稳归零，静止后自动停止帧回调，零常驻开销。
- **动态流光联动与零裁切保护**：
  - 拖动时同步联动触控板表面与移动把手的液态玻璃倾斜高光（移动前缘提亮、尾缘微暗）；
  - 全角点精确包络限幅，确保任意方向与任意面板宽高比下均不发生窗口边缘裁切。

## Install

`versionCode 102`, `versionName 0.5.89`, same signing key as before. Installs over previous versions.
