# OpenTouchpad v0.5.87

### 触控板双模态默认材质：高不透明度 Material You ⇄ 中低不透明度 Apple 液态玻璃 ✨

无需额外的材质切换开关，触控板与气泡按键现在直接随「触控板透明度」滑块自动呈现与连续融合两套默认材质：

- **高不透明度 Material You 动态色调材质（80%–100%）**：
  - Android 12+（API 31+）默认自动提取系统壁纸 Monet 动态色板（`system_neutral1_*`、`system_accent1_*`、`system_accent2_*`），让触控板自然融入手机桌面主题；
  - Android 8–11 自动按动态配色设置或经典暖色系 M3 容器色板呈现，并按视觉角色区分触控板底面、常规气泡按键与移动/缩放把手按键的三级色彩层级；
- **中低不透明度 Apple 透明液态玻璃材质（20%–60%）**：
  - 在 `TouchpadSurfaceView` 与 `BubbleDrawable` 中渲染四层光学质感：135° 斜向通透焦散基底（消除半透明纯色的灰雾感）、左上凸透镜内部聚光光斑、内缩 `1.1dp` 液态表面张力内高光弧与底部折射反光，以及四段式菲涅尔不对称双高光折光描边；
  - 完整兼容自定义触控板底图与饱满气泡圆角弧度；
- **平滑演进与 3D 按压实时流光（60%–80%）**：
  - 随透明度滑块在 `60%–80%` 之间通过三次 Hermite 曲线连续过渡；
  - 深度联动 `PressFeedback` 3D 按压倾斜引擎，手指按压或滑动触控板与气泡按键时，液态玻璃高光与焦散焦点实时跟手流动；
- **深浅色模式实时同步**：
  - 修复触控板无障碍服务 `isDarkTheme()` 此前固定返回深色的问题，切换浅色 / 深色 / 跟随系统主题时，触控板、气泡按键、悬浮球与点击光圈立即同步刷新。

## Install

`versionCode 100`, `versionName 0.5.87`, same signing key as before. Installs over previous versions.
