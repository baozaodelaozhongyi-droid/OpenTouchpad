# OpenTouchpad v0.6.2

### 按压物理反馈重构、恢复纯粹线性跟手 & 触边微震开关 🛠️

- **恢复纯粹 `1:1` 线性光标位移（消除减速急刹与飞走）**：
  - 移除动态倍率对光标移动步长的干预，恢复 `dx * sensitivity` 纯线性可预期跟手映射，消除靠近小目标减速时的顿挫感与加力滑出时的窜动感；
  - 修复速度平滑器在方向折返过零时的残余分量抵消问题。
- **重做按压物理弹簧反馈（根除白光闪烁与短按抽搐）**：
  - **触控板流光柔和化**：将 `TouchpadSurfaceView` 按压流光遮罩 Alpha 从 `60..100` 收敛至 `<= 24` 并降低高光增益，消除轻触瞬间全板闪白现象；
  - **触控板与按钮连续二阶弹簧**：`PressFeedback` 改用基于 `Choreographer` 的连续二阶质量-弹簧-阻尼驱动并支持短按向下初速度动量延续——`30–50ms` 快速轻点也能自然走完一段饱满的软垫下压弧线，再以近临界阻尼（`zeta = 0.84`）温润回升归位，全程零动画腰斩与跳变，收敛即停帧；
  - **光标单向柔和呼吸**：移除落指放大与点击时的零毫秒位置瞬移跳变，点击改为纯速度脉冲驱动的单向柔和下压与回升（`1.0 → ~0.90 → 1.0`，`zeta = 0.85`），并调高微摆与触边挤压阻尼。
- **新增「光标触边微震反馈」独立开关**：
  - 在「操作手感与反馈 → 触感震动反馈」下方新增独立的「光标触边微震反馈」（`edgeHaptics`）开关，支持随主震动开关联动折叠并实时生效。
- **单元测试**：`TouchpadMathTest` 更新并新增 114 行，覆盖连续二阶按压弹簧短按动量延续、近临界阻尼收敛及更新后的光标动力学包络。

## Install

`versionCode 115`, `versionName 0.6.2`, same signing key as before. Installs over previous versions.
