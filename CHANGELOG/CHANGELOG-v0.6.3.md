# OpenTouchpad v0.6.3

### 动态指针倍率独立开关 & 三项自定义参数 🎛️

- **动态指针倍率开关与实时自定义滑块**：
  - 在「操作手感与反馈 → 光标移动灵敏度」下方新增**「动态指针倍率」**开关（默认关闭，保持纯粹 `1:1` 线性移动；开启后平滑展开三项参数滑块，拖动滑块实时生效无需重建窗口）：
    - **慢移最低倍率**（`0.50× ～ 1.00×`，默认 `1.00×`）：默认 `1.00×` 完全关闭慢移减速区，避免靠近小目标时急刹车；需要降速微瞄时可自由调低；
    - **快滑最高倍率**（`1.00× ～ 2.50×`，默认 `1.45×`）：按个人手速与屏幕尺寸控制快速拨动时的最高灵敏度放大倍数；
    - **提速触发速度**（`60 ～ 400 dp/s`，默认 `160 dp/s`）：控制手指超过多快才开始平滑提速，数值越高日常滑动越稳重。
- **两段式 $C^1$ 平滑曲线与无符号标量速率滤波**：
  - 采用两段式 $C^1$ 连续单调曲线衔接微瞄区、常速区与提速区，全程无折角突跳；
  - 改用触控板原始手指位移的**无符号标量速率**（`hypot(dx, dy) / dt`）驱动倍率计算，彻底修复在小按钮附近来回折返或画圈时正负速度抵消过零造成的急刹问题。
- **单元测试**：`TouchpadMathTest` 新增并更新 190 行测试，覆盖默认/自定义曲线单调性与边界保护、VRR 多刷新率一致性及高速折返防急刹验证。

## Install

`versionCode 116`, `versionName 0.6.3`, same signing key as before. Installs over previous versions.
