# OpenTouchpad v0.5.90

### 修复主题切换圆形扩散动效与状态栏内容重叠 ✨

针对设置页在 Android 15 全面屏下的滚动重叠以及主题切换圆形扩散动画中的视觉瑕疵进行了全面修复：

- **消除滚动时与顶部状态栏重叠**：
  - 为设置页引入专用滚动容器 `SettingsScrollView`，按系统状态栏与挖孔区域高度补足顶部留白并开启 `clipToPadding = true`，防止页面向下滚动后文字与顶部时间、信号等系统图标重叠；
  - 顶部滚动时自动叠加柔和的 `16dp` 渐隐边缘，底部仍保持通透并将手势导航栏安全区移至内容容器底部，兼顾全面屏观感与可读性。
- **修复主题切换圆形扩散动效的背景同步与重影问题**：
  - 在 `RevealLayout` 圆形裁剪层内同步绘制目标主题页面底色（及自定义设置壁纸与对应主题的半透明遮罩），彻底消除扩散过程中背景不同步、文字重影闪烁及收尾闪跳问题；
  - 新增圆波覆盖检测逻辑，在扩散圆波扫过状态栏与导航栏位置瞬间自动切换系统栏图标深浅，快速连点打断或逆向回退时图标深浅亦随之平滑还原。
- **完善切换过程中的状态同步与资源回收**：
  - 同步更新主题切换后的状态胶囊配色、外观分组摘要标签，以及回退底层主题时相关开关与滑块控件的引用恢复；
  - 清理壁纸或销毁页面时先行解除扩散层对壁纸 `Bitmap` 的引用，避免资源回收异常。

## Install

`versionCode 103`, `versionName 0.5.90`, same signing key as before. Installs over previous versions.
