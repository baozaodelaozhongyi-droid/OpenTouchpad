# OpenTouchpad v0.5.88

### 优化低透明度下的液态玻璃质感与边缘反光 ✨

针对低不透明度模式下玻璃高光偏重、边缘反光偏亮的问题进行精细光学调校：

- **轻盈细腻的菲涅尔玻璃边缘**：
  - 将液态玻璃外描边由 `1.25dp` 收细至 `0.88dp`，主高光 Alpha 由 `165..225` 下调至 `76..124`，同步收敛侧边与右下反光强度，使轮廓通透清晰而不刺眼；
  - 完善 `60%–80%` 过渡区与 Material You 描边的连续衔接。
- **消除内外双高光叠白**：
  - 引入随透明度收敛的内部高光衰减系数，收细并大幅调轻表面张力内高光弧（`1.1dp` → `0.75dp`）与底部折光反光，避免与外描边叠加形成厚重白边。
- **更清透的玻璃基底与自定义底图**：
  - 降低玻璃基底混白与内部焦散光斑浓度，去除低透明度下的灰雾感；
  - 为自定义触控板底图增加焦散衰减保护，保持背景画面干净通透，同时保留按压 3D 倾斜实时流光反馈。

## Install

`versionCode 101`, `versionName 0.5.88`, same signing key as before. Installs over previous versions.
