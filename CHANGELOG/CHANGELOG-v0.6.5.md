# OpenTouchpad v0.6.5

### 长按自定义菜单交互细节优化

- **恢复自定义菜单原始高度与居中样式**：
  - 恢复「选择功能动作」弹窗原本的居中与自然高度显示，同时完整保留悬浮触控板与光标显示在弹窗上方、可直接移动光标滚动与点选动作的能力。
- **收起 / 展开触控板不再误关自定义菜单**：
  - 修复在长按自定义菜单显示期间点击收起（最小化为悬浮球）或从悬浮球重新展开触控板时，因面板重建触发 `dismissActiveDialog()` 导致菜单被一并关闭的问题；
  - 菜单打开期间可随时收起触控板避让视线、或重新展开继续用光标操作（展开后自动将光标重新置顶至菜单与面板上方）。

## Install

`versionCode 118`, `versionName 0.6.5`, same signing key as before. Installs over previous versions.
