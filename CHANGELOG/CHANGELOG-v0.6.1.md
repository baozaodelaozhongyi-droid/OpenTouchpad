# OpenTouchpad v0.6.1

### 光标动态加速度、物理微动效 & 线性马达触觉分层 ✨

- **动态指针加速度曲线（Pointer Ballistics）**：
  - 慢速微瞄区间（`<= 22 dp/s`）平滑收敛至 `0.64×` 增益，指尖轻推对准细小按钮稳而不飘，100% 保留纯粹手指自由控制权；
  - 中速巡航（`135 dp/s`）平滑通过 `1.00×` 基准灵敏度，快速轻甩（`300–900+ dp/s`）$C^1$ 连续渐进升至 `1.80×` 上限，单手轻拨即可跨屏；
  - 支持首包播种、`< 1.5ms` 合包位移累积与 VRR 时间常数滤波，60 / 120 / 240Hz 触控与刷新率下手感一致。
- **光标本体物理微动效（锁死尖端热点，零位图重绘）**：
  - 严格围绕箭头尖端热点 `(hx, hy)` 执行 Canvas 变换，100% 复用 2× 超采样 `cachedBitmap`，真实落点与尖端像素严丝合缝；
  - **触板唤醒感**：手指触碰触控板时轻微浮起（`1.035×`），松手自然回落；
  - **点击啄击感**：点击瞬间向尖端干脆下压（`~0.84×`）并微弹回正；
  - **长按蓄力前馈 → 咬合展开**：静止按住满 `130ms` 后平滑向尖端内聚蓄力（缩至 `0.87×`），中途滑开自动舒展取消，到达长按阈值或开启拖拽锁定瞬间弹开进入紧致抓握姿态（`0.94×`）；
  - **顺风微摆与撞边微挤压**：高速移动时箭尾产生克制的阻尼微摆（封顶 `±5.0°`），顶住屏幕边缘继续外推产生最高 `7%` 的柔和弹性挤压；系统级手势取消（非用户连击打断）时附带短暂受阻微抖提示；动力学收敛后立即停帧，LTPO 静置零唤醒。
- **多级线性马达触觉语法分层**：
  - 扩展撞边微刻度（`CLOCK_TICK`，含同轴 `14dp` 脱离重武装迟滞与 `180ms` 冷却，贴边滑动绝不连震）、清脆点击（`VIRTUAL_KEY`）、长按/拖拽扎实咬合（`CONFIRM` / `LONG_PRESS`）、松手轻盈卸力（`GESTURE_END` / `KEYBOARD_TAP`）与系统拦截受阻反馈（`REJECT`），并消除拖拽锁定按键的双重重复震动。
- **单元测试**：`TouchpadMathTest` 新增 223 行，覆盖指针加速度曲线单调性/上下界、VRR 多刷新率一致性、长按蓄力进度曲线、光标弹簧包络收敛及边缘触感迟滞状态机。

## Install

`versionCode 114`, `versionName 0.6.1`, same signing key as before. Installs over previous versions.
