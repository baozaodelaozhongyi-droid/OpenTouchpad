## v0.5.0 — warm editorial look

### Settings page
- New warm palette: parchment background (#F5F4ED), ivory cards, warm grey text, terracotta accent (#C96442). Dark mode uses warm charcoal (#1F1E1D / #262624) with coral accent (#D97757). No cool blue-greys left.
- Serif headings: app title and section titles use a bundled subset of Noto Serif SC Medium (89 KB, OFL). Body and controls stay on the system sans font.
- Header is plain parchment with a large serif title, a warm status chip and a terracotta primary button (no gradient).
- Value tags, segmented control, switches, sliders and colour rings all follow the new palette; dialogs use the same colours and a serif title.
- Fixed: on Android 15 the page was drawn under the status bar. Content is now padded by the system bar insets.

### Touchpad overlay
- Buttons, touchpad and handles use the same warm neutrals; move/resize handles are terracotta.
- Default floating ball colour is terracotta. The colour list is now warm/earthy tones.

### Install
`versionCode 13`, same signing key as before. Installs over the previous version.
